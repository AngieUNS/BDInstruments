Skalar lanzará una nueva tecnología de automatización; El analizador discreto BluVisionTM, para el análisis de los parámetros colorimétricos básicos.

El BluVisionTM está especialmente diseñado para los laboratorios ambientales que tienen una amplia variedad de tipo de muestras y matrices para hacer análisis. El analizador discreto de Skalar automatiza la muestra & reactivo pipeteando estos en las cubetas, mezclándolos, calentándolos y midiendo el producto de la reacción.

Con el analizador discreto BluVisionTM nosotros complementamos nuestra gama de productos para la automatización del análisis colorimétrico, que ya está conformado por el analizador de flujo continuo San++ y el analizador robótico SP2000 para kits de ensayo.

## Operación

El BluVision tiene 100 posiciones de muestreo divididos en 5 gradillas de 20 muestras cada una. El rango de volumen de muestra puede variar entre 3.5 a 10 ml. Para los reactivos, estándares (stock) y controles de calidad, el analizador dispone de 30 posiciones para un volumen de hasta 50ml. Las gradillas para las muestras y reactivos pueden enfriarse durante la corrida del análisis.

El analizador está equipado con una bandeja de cubetas de 160 posiciones. Los bloques de las cubetas se cargan automáticamente en la bandeja a través de un sistema de cargador automático. El cargador automático tiene bloques de cubetas adicionales, dando un total de 640 pruebas que se pueden correr sin la intervención del operador. La bandeja de cubetas es de temperatura controlada.

Los bloques de las cubetas son desechables, lo que elimina cualquier contaminación entre muestras. Los bloques de cubetas usadas se almacenan en una cesta de basura para su eliminación segura después del análisis. Si se utilizan productos químicos tóxicos, los bloques de cubetas pueden ser desechados por separado para evitar la contaminación con el resto de los residuos.

El instrumento utiliza una aguja para dispensar la muestra y el reactivo en las cubetas. La aguja puede precalentar las muestras y los reactivos antes de ser dispensados. Una bomba de larga durabilidad y de alta precisión se utiliza para el pipeteado de la muestra y del reactivo.

El detector del analizador BluVision está equipado con una fuente de luz halógena y con un portafiltros que contiene 8 filtros con longitudes de onda diferentes. El BluVision es por lo tanto capaz de correr hasta 8 parámetros diferentes al mismo tiempo sin ninguna intervención del operador. Los filtros se pueden cambiar fácilmente para diferentes parámetros.

La cubeta tiene una longitud óptica de 15 mm, lo que permite una detección precisa de niveles bajos de ppb.

El BluVision ofrece un analizador automático «de inasistencia» verdadero, el cual crea las calibraciones de soluciones stock, auto-diluye muestras fuera de rango o realiza el re-análisis de muestras, todo en una sola corrida.

## Software

El analizador discreto BluVisionTM está totalmente controlado por computador. El instrumento tiene una pantalla táctil integrada, que muestra toda la información relevante del instrumento, por ejemplo, del estado del analizador, las temperaturas de las bandejas y cubetas de muestreo. Además, una serie de comandos se pueden ejecutar desde esta pantalla, tales como la carga del bloque de las cubetas, el cambio de filtros, etc.

Para correr el análisis, recopilar y calcular los resultados, el analizador utiliza un paquete de software comprensivo, el DiscreteAccessTM, que cumple con todos los requisitos actuales de laboratorio. Una interface de usuario fácil de usar permite al operador poner en marcha el analizador en cuestión de segundos. Cada corrida de análisis puede ser configurada por lotes o aleatorio. Para cada muestra, el usuario escribe la identificación de la muestra o los baja del LIMS, luego, selecciona los parámetros analíticos deseados para ser analizados e inicia el analizador.

El analizador automáticamente pre-diluye muestras o si una muestra va fuera de rango durante el análisis, la muestra es automáticamente re-analizada en un rango analítico diferente o re-analizada después de una dilución posterior automática.

Se ofrecen protocolos de control de calidad extensos, tales como CLP y 21 CFR parte 11, que incluye protección de contraseña, integridad de datos, seguridad de datos y auditorías. Los resultados finales se pueden imprimir utilizando un formato de reporte definido por el usuario o exportar a LIMS para la posterior manipulación de datos.

## Aplicaciones

El BluVisionTM es ideal para el análisis de muchos diferentes análisis colorimétricos en una variedad de tipos de muestras y matrices que se encuentran en los laboratorios ambientales de hoy en día. Las áreas de aplicación típicas para el BluVision son, por ejemplo, agua potable, aguas residuales, aguas subterráneas y aguas superficiales.
