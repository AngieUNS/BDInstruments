## Extractor de CO2 supercrítico totalmente automatizado SFT-130A

El SFT-130A SFE es un sistema avanzado de extracción de fluidos supercríticos. Combina el fácil funcionamiento de un SFE de mesa con muchas características que normalmente sólo se encuentran en sistemas de escala piloto más grandes y costosos. El SFT-130A es ideal para una variedad de aplicaciones, desde investigación básica hasta desarrollo de procesos. Este sistema SFE fue desarrollado para investigar la aplicación de la extracción con fluidos supercríticos a una amplia variedad de desafíos analíticos y de procesamiento de materiales.

## SFT-NPX-10

El sistema de procesamiento SFT-NPX-10 está diseñado para realizar extracciones de fluidos supercríticos incorporando recipientes de muestra simples o dobles opcionales de 5, 10 o 20 litros con separadores simples o dobles opcionales y controles de interfaz integrados. El sistema incluye características que facilitan la transición de nuestros equipos a escala de laboratorio a sistemas de procesamiento de producción.
