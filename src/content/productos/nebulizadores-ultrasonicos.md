Marca: Teledyne Cetac
 
 
 
 
 Modelo: U5000AT +

El U5000AT + Nebulizador ultrasónico ofrece hasta 10x límites de detección elemento inferior para ICP-AES y ICP-MS. Las muestras se introducen en un transductor piezoeléctrico de alta eficiencia, lo que proporciona una mayor eficiencia de transporte de muestras al ICP.

Mayor eficiencia de nebulización: los nebulizadores neumáticos convencionales generalmente tienen una eficiencia de solo 2-3% en condiciones normales de operación. El transductor piezoeléctrico del U5000AT + convierte más muestra líquida en un aerosol utilizable, con una eficiencia del 10 al 15%. El resultado es una mejora de hasta 10 veces en la señal del analito.

Límites de detección inferiores: con ICP-AES, los límites de detección de instrumentos (IDL) caen por debajo de 1 ppb para muchos elementos. Para ICP-MS, los límites sub-ppt se pueden alcanzar teniendo en cuenta las fuentes de contaminación: impurezas de reactivos, recipientes de solución, entorno de laboratorio.

Estabilidad a corto y largo plazo: la estabilidad de la señal a corto y largo plazo (1 hora) es excelente, con% RSD típicamente <1%.

Menos ajustes: el U5000AT + tiene un oscilador de autoajuste para un funcionamiento estable. No es necesario ningún ajuste para diferentes tipos de muestras (acuosas u orgánicas).

Desolvatación incorporada: se utiliza un sistema de desolvatación electrotérmica incorporado eficiente en lugar de un enfriador de recirculación. La desolvatación electrotérmica evita la sobrecarga de disolvente del ICP, ahorra espacio en la mesa de laboratorio y reduce el mantenimiento. Una bomba de drenaje incorporada elimina el exceso de líquido de muestra de la cámara de pulverización y los condensadores.

Configuración rápida: todas las unidades U5000AT + se proporcionan con un kit de interfaz para una conexión rápida y fácil al host ICP-AES o ICP-MS. El kit incluye una línea de gas nebulizador y una línea de salida de muestra con el adaptador de antorcha ICP adecuado.

Fácil operación: una vez que la muestra de líquido se haya introducido en el U5000AT + , simplemente presione el botón de operación amarillo para generar el aerosol. Las muestras líquidas se pueden introducir continuamente a través de un muestreador automático como el CETAC ASX-280/560. Operación de mesa: El U5000AT+ tiene un tamaño compacto (35,6 cm de ancho x 34,9 cm de profundidad), lo que permite colocarlo en una mesa de trabajo o carro de laboratorio.

Diseño modular: un diseño modular permite un fácil reemplazo de todo el conjunto de cristalería. Esta característica única puede ser útil cuando se cambia entre tipos de muestras muy diferentes (por ejemplo, sólidos bajos en disolución frente a sólidos en alta disolución; acuosos frente a orgánicos). Se puede agregar un desolvador de membrana opcional (CETAC MDX-200) al U5000AT+ para eliminar más el disolvente de la muestra (acuoso u orgánico volátil).

## Nebulizadores Ultrasónicos

Marca: Teledyne Cetac
 
 
 
 
 Modelo: U6000AT +

El U6000AT + añade un módulo de desolvatación membrana a la norma U5000AT + nebulizador ultrasónico para mejorar la reducción de interferencias con base de disolvente, en particular para disolventes orgánicos volátiles (ambos tipos polares y no polares).

Uso con ICP-AES: Para ICP-AES, el U6000AT + se usa principalmente para la introducción de disolventes orgánicos volátiles. Estos disolventes pueden causar una serie de problemas graves: pérdida de plasma, inestabilidad del plasma, fondo de alta emisión de carbono y acumulación de carbono en la antorcha ICP.

Uso con ICP-MS: para ICP-MS, el U6000AT + se puede usar tanto para muestras orgánicas volátiles como acuosas

Mayor eficiencia de nebulización: el transductor piezoeléctrico del U6000AT + convierte más muestra líquida en un aerosol utilizable, con una eficiencia del 10-15%. Con el módulo de membrana conectado, el resultado es una mejora de 2 a 5 veces la señal del analito en comparación con un nebulizador neumático estándar.

Reducción de las interferencias a base de solventes: El desolvador de membrana de fluoropolímero inerte reduce las interferencias a base de solventes del agua y el vapor orgánico. Por ejemplo, el% CeO / Ce es típicamente <0.05% para muestras a base de agua con el U6000AT + . Las inerferencias basadas en carbono, como 12 C 2+ , también se reducen en gran medida, lo que permite la detección de Mg en m / z = 24.

Límites de detección mejorados: la combinación de mejora de la señal y reducción de interferencias permite límites de detección de instrumentos más bajos para ICP-AES e ICP-MS.

Configuración sencilla: todas las unidades U6000AT + se proporcionan con un kit de interfaz para una conexión rápida y sencilla al host ICP-AES o ICP-MS. El kit incluye una línea de gas nebulizador y una línea de salida de muestra con el adaptador de antorcha ICP adecuado. Además, se incluye un kit de enjuague para limpiar el desolvador de membranas.

Diseño compacto: el U6000AT + consta del nebulizador ultrasónico U5000AT + estándar y una caja de desolvador de membrana modular. El U5000AT + simplemente se coloca encima de la caja del desolvador, lo que ahorra un valioso espacio en la mesa; el tamaño del U6000AT + es de 35,6 cm de ancho x 34,9 cm de profundidad .

Flexibilidad : el módulo desolvador de membrana se puede desconectar fácilmente del nebulizador ultrasónico si la desolvación de la membrana no es necesaria para una aplicación en particular. Esta característica permite el funcionamiento autónomo del nebulizador ultrasónico.
